⏱️ Stretch length 8–30s

Each groove is held for a random time between these two handles before things change. Left = shortest a stretch can be, right = longest. Set both to the same spot for a fixed length.

🎢 Drift within a stretch None → Small

Each stretch rolls a random drift strength between these handles — how much the tempo speeds up or slows down as it plays out. Left = calmest it can be, right = wildest. Set both to the left for zero drift.

No changeSmallBig

🌫️ Transition blend 0.8s

When the tempo moves to a new stretch, glide into it over this many seconds instead of switching instantly. 0 = snap to the new tempo, 5 = long smooth ramp.

Snap 0s2.5sGlide 5s

🎯 Tempo range

Push and pull the two handles to fence in the tempo. It will never drop below the low end or rise above the high end.

Floor 70 BPM Ceiling 110 BPM
